ARITHMETIC

నిష్పత్తి - అనుపాతం (RATIO - PROPORTION)

  • ఒకే ప్రమాణం గల రెండు రాశులను భాగాహారం ద్వారా సరిపోల్చడాన్ని నిష్పత్తి అంటారు.
  • రెండు రాశుల మధ్య నిష్పత్తిని సూచించుటకు భాగాహార ప్రక్రియను ఉపయోగిస్తారు.
  • \(a, b\) ల నిష్పత్తిని \(a : b\) గా సూచిస్తారు.
  • \(a : b = a \div b = \frac{a}{b}\)
  • \(a : b\) లో \(a\) ను పూర్వ పదం (Antecedent) అంటారు, \(b\) ను పర పదం (Consequent) అంటారు.
  • నిష్పత్తికి ప్రమాణాలు ఉండవు.
  • నిష్పత్తి అనేది కేవలం సంఖ్యారూపం మాత్రమే.

కనిష్ట నిష్పత్తి లేదా సామాన్య నిష్పత్తి (LEAST RATIO):

నిష్పత్తిలో పదాలకు 1 మాత్రమే ఉమ్మడి కారణాంకంగా ఉంటే ఆ నిష్పత్తిని కనిష్ట నిష్పత్తి అంటారు.

  • \(4 : 24\) నిష్పత్తి యొక్క కనిష్ట నిష్పత్తి \(= 1 : 6\)
  • \(5 : 125\) నిష్పత్తి యొక్క కనిష్ట నిష్పత్తి \(= 1 : 25\)

తుల్య నిష్పత్తులు లేదా సమాన నిష్పత్తులు (EQUAL RATIOS):

ఏదైనా నిష్పత్తిలో రెండు పదాలను ఒకే సహజ సంఖ్యచే గుణిస్తూ పోతే వచ్చు నిష్పత్తులను తుల్య నిష్పత్తులు లేదా సమాన నిష్పత్తులు అంటారు.

ఉదాహరణకు, \(1 : 6\) నిష్పత్తి యొక్క సమాన నిష్పత్తులు: \(2:12, 3:18, 4:24, 5:30, 6:36, 7:42, \dots\)

గమనిక: నిష్పత్తిలోని రెండు పదాలను ఏదైనా సంఖ్యచే గుణించినా లేదా భాగించినా నిష్పత్తి యొక్క విలువ మారదు.

\(\frac{2}{3} \times \frac{4}{4} = \frac{8}{12}\) (అనగా \(2 : 3 = 8 : 12\))

ముఖ్యమైన సూత్రాలు:

  • \(a : b\) యొక్క వర్గ నిష్పత్తి \(= a^2 : b^2\)
  • \(a : b\) యొక్క ఘన నిష్పత్తి \(= a^3 : b^3\)
  • \(a : b\) యొక్క వర్గమూల నిష్పత్తి \(= \sqrt{a} : \sqrt{b}\)
  • \(a : b\) యొక్క ఘనమూల నిష్పత్తి \(= \sqrt[3]{a} : \sqrt[3]{b}\)
  • \(a : b\) యొక్క విలోమ నిష్పత్తి \(= \frac{1}{a} : \frac{1}{b} = b : a\)
  • \(a : b : c\) యొక్క విలోమ నిష్పత్తి \(= \frac{1}{a} : \frac{1}{b} : \frac{1}{c} = bc : ac : ab\)

అనుపాతం (PROPORTION):

  • 2 నిష్పత్తుల సమానత్వాన్ని అనుపాతం అంటారు. (\(a : b = c : d\) లేదా \(a : b :: c : d\))
  • \(::\) (Is as to) అనే చిహ్నాన్ని పరిచయం చేసినవాడు: ఓగ్ ట్రాడ్ (1628)
  • \(a, b\) ల నిష్పత్తి, \(c, d\) ల నిష్పత్తికి సమానం అయితే \(a, b, c, d\) లు అనుపాతంలో ఉంటాయి.
  • ఇందులో \(a, d\) లను అంత్యములు (EXTREMES) అని, \(b, c\) లను మధ్యములు (MEANS) అని అంటారు.
  • \(a, b, c, d\) లు అనుపాతంలో ఉంటే: అంత్యముల లబ్ధం = మధ్యముల లబ్ధం (\(ad = bc\))
  • చతుర్థ అనుపాతం (Fourth Proportional): \(d = \frac{bc}{a}\)
  • తృతీయ అనుపాతం (Third Proportional): \(c = \frac{b^2}{a}\) (\(a, b, b, c\) లు అనుపాతంలో ఉన్నప్పుడు)
  • మధ్యమ అనుపాతం (Mean Proportional): \(b^2 = ac \Rightarrow b = \sqrt{ac}\)

బహుళ నిష్పత్తి (MULTIPLE RATIO / COMPOUND RATIO):

  • రెండు నిష్పత్తులలో ఉండే పూర్వ పదాల లబ్ధం, పరపదాల లబ్ధాల మధ్య నిష్పత్తిని బహుళ నిష్పత్తి అంటారు.
  • \(a : b\) & \(c : d\) నిష్పత్తుల బహుళ నిష్పత్తి \(= \frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd} = ac : bd\)

రేటుగా నిష్పత్తి (Ratio as Rate):

  • హృదయ స్పందన : 72 స్పందనలు / నిముషం
  • జననాల రేటు : 21 / 1000
  • వేగం రేటు : 60 km / గంట
  • ధర రేటు : ₹120 / kg

అనుపాత రకాలు:

  • అనులోమానుపాతం (DIRECT PROPORTION): రెండు రాశులు అనులోమానుపాతంలో ఉన్నచో ఒక రాశి విలువ పెరిగితే రెండో రాశి విలువ కూడా పెరుగును, ఒక రాశి విలువ తగ్గితే రెండో రాశి విలువ కూడా తగ్గును. (ఉదా: కొనే వస్తువుల సంఖ్య పెరిగితే చెల్లించాల్సిన మొత్తం పెరుగును; ప్రయాణ దూరం పెరిగితే ప్రయాణ సమయం పెరుగును).
  • విలోమానుపాతం (INVERSE PROPORTION): రెండు రాశులు విలోమానుపాతంలో ఉన్నచో ఒక రాశి విలువ పెరిగితే రెండో రాశి విలువ తగ్గును, ఒక రాశి విలువ తగ్గితే రెండో రాశి విలువ పెరుగును. (ఉదా: ధరలు పెరిగితే డిమాండ్ తగ్గడం; మంది ఎక్కువైతే మజ్జిగ పల్చబడటం).
  • మిశ్రమానుపాతం (MIXED PROPORTION): రెండు కంటే ఎక్కువ రాశులు మిశ్రమానుపాతంలో ఉన్నచో ఒక రాశిలో మార్పు, మిగిలిన రాశులలో మార్పుకు కారణం అగును. (ఉదా: ఫోన్‌లో గడిపే సమయం పెరిగితే మార్కులు తగ్గడం).
1. 16, 9 ల మధ్యమ అనుపాతం ఎంత?
ఇచ్చినవి \(a = 16\), \(c = 9\)
మధ్యమ అనుపాతం \(b = \sqrt{ac}\)
\(b = \sqrt{16 \times 9} = \sqrt{144}\)
= 12
2. 16, 36 ల తృతీయ అనుపాతం ఎంత?
ఇచ్చినవి \(a = 16\), \(b = 36\)
తృతీయ అనుపాతం \(c = \frac{b^2}{a}\)
\(c = \frac{36 \times 36}{16}\)
= 81
3. 5, 8, 15 ల చతుర్థ అనుపాతం ఎంత?
ఇచ్చినవి \(a = 5\), \(b = 8\), \(c = 15\)
చతుర్థ అనుపాతం \(d = \frac{bc}{a}\)
\(d = \frac{15 \times 8}{5}\)
= 24
4. 7 : 11 యొక్క వర్గ నిష్పత్తి ఎంత?
\(7 : 11\) యొక్క వర్గ నిష్పత్తి \(= 7^2 : 11^2\)
= 49 : 121
5. 196 : 289 యొక్క వర్గమూల నిష్పత్తి ఎంత?
\(196 : 289\) యొక్క వర్గమూల నిష్పత్తి \(= \sqrt{196} : \sqrt{289}\)
= 14 : 17
6. 3 : 5 యొక్క ఘన నిష్పత్తి ఎంత?
\(3 : 5\) యొక్క ఘన నిష్పత్తి \(= 3^3 : 5^3\)
= 27 : 125
7. 8 : 27 యొక్క ఘన మూల నిష్పత్తి ఎంత?
\(8 : 27\) యొక్క ఘన మూల నిష్పత్తి \(= \sqrt[3]{8} : \sqrt[3]{27}\)
= 2 : 3
8. 3 : 4 యొక్క విలోమ నిష్పత్తి ఎంత?
\(3 : 4\) యొక్క విలోమ నిష్పత్తి \(= \frac{1}{3} : \frac{1}{4}\)
= 4 : 3
9. 2 : 3 : 4 యొక్క విలోమ నిష్పత్తి ఎంత?
\(2 : 3 : 4\) యొక్క విలోమ నిష్పత్తి \(= (3 \times 4) : (2 \times 4) : (2 \times 3)\)
\(= 12 : 8 : 6\)
= 6 : 4 : 3
10. 2 : 3 కు సమానం కాని నిష్పత్తి ఏది? (4:6, 10:15, 6:9, 7:4)
ప్రతి నిష్పత్తిని సూక్ష్మీకరించగా: \(4:6 = 2:3\), \(10:15 = 2:3\), \(6:9 = 2:3\)
సమానం కాని నిష్పత్తి = 7 : 4
11. క్రింది నిష్పత్తుల్లో ఏవి అనుపాతంలో లేవో గుర్తించండి.
  • \(2 : 3\) & \(22 : 33\) \(\Rightarrow \frac{2}{3} = \frac{22}{33}\) (అనుపాతంలో ఉన్నవి)
  • \(15 : 30\) & \(7 : 14\) \(\Rightarrow \frac{1}{2} = \frac{1}{2}\) (అనుపాతంలో ఉన్నవి)
  • \(5 : 10\) & \(16 : 8\) \(\Rightarrow \frac{1}{2} \neq \frac{2}{1}\) (అనుపాతంలో లేవు)
అనుపాతంలో లేనిది = 5 : 10 & 16 : 8
12. క్రింది ఖాళీలను పూరించండి.
1) \(\underline{2} : 5 = 6 : 15\)
2) \(16 : 20 = \underline{28} : 35\)
13. 'MISSISSIPPI' అనే పదంలోని అచ్చుల సంఖ్యకు, హల్లుల సంఖ్యకు ఉండే నిష్పత్తిని కనిష్ట పదాలలో రాయండి.
TYPE 1 (మొత్తం అక్షరాల ఆధారంగా):
అచ్చుల సంఖ్య (I) = 4
హల్లుల సంఖ్య (M, S, P) = 7
అచ్చులు : హల్లులు = 4 : 7

TYPE 2 (ఒకే రకమైన అక్షరాలను ఒకటిగా భావిస్తే):
అచ్చుల సంఖ్య = 1 (I)
హల్లుల సంఖ్య = 3 (M, S, P)
అచ్చులు : హల్లులు = 1 : 3
14. 5 : 8, 3 : 4 లో పెద్ద నిష్పత్తిని గుర్తించండి.
\(\frac{5}{8}\) మరియు \(\frac{3}{4}\) లను అడ్డ గుణకారం చేయగా:
\(5 \times 4 = 20\), \(8 \times 3 = 24\)
20, 24 లలో పెద్ద సంఖ్య 24
పెద్ద నిష్పత్తి = 3 : 4
15. 7 : 15, 13 : 25 లో చిన్న నిష్పత్తిని గుర్తించండి.
\(\frac{7}{15}\) మరియు \(\frac{13}{25}\) లను అడ్డ గుణకారం చేయగా:
\(7 \times 25 = 175\), \(15 \times 13 = 195\)
175, 195 లలో చిన్న సంఖ్య 175
చిన్న నిష్పత్తి = 7 : 15
16. 4 నిమిషాలకు, 30 సెకన్లకు గల నిష్పత్తి ఎంత?
4 నిమిషాలు \(= 4 \times 60 = 240\) సెకన్లు
నిష్పత్తి \(= 240 : 30\)
= 8 : 1
17. 30 వస్తువులకు, ఒక స్కోరుకు మధ్య గల నిష్పత్తి ఎంత?
1 స్కోరు = 20 వస్తువులు
నిష్పత్తి \(= 30 : 20\)
= 3 : 2
18. 3 రీములకు, 80 దస్త్రాలకు మధ్యగల నిష్పత్తి ఎంత?
1 రీము = 20 దస్త్రాలు, కావున 3 రీములు \(= 3 \times 20 = 60\) దస్త్రాలు
(కాగితాల ప్రకారం: 3 రీములు \(= 3 \times 480 = 1440\), 80 దస్త్రాలు \(= 80 \times 24 = 1920\))
దస్త్రాల నిష్పత్తి \(= 60 : 80 = 3 : 4\) (లేదా పుస్తకంలో పేర్కొన్న ప్రకారం \(3(24) : 80(480)\))
= 3 : 4 (లేదా 3 : 1600)
19. \(\frac{1}{4} : \frac{1}{3}\) అనే నిష్పత్తి దేనికి సమానం అగును?
అడ్డ గుణకారం చేయగా:
= 3 : 4
20. \(5\frac{1}{2} : 2\frac{2}{3}\) అనే నిష్పత్తి దేనికి సమానం అగును?
మిత్ర భిన్నాలను క్రమ భిన్నాలుగా మార్చగా: \(\frac{11}{2} : \frac{8}{3}\)
అడ్డ గుణకారం చేయగా: \(11 \times 3 : 2 \times 8\)
= 33 : 16
21. \(a : b = 3 : 4\) అయితే \(3a + 2b : 2a + 5b\) విలువ ఎంత?
\(a = 3, b = 4\) విలువలను ప్రతిక్షేపించగా:
\(3(3) + 2(4) : 2(3) + 5(4)\)
\(= 9 + 8 : 6 + 20\)
= 17 : 26
22. \(\frac{a}{b} = \frac{3}{5}\) మరియు \(\frac{b}{c} = \frac{4}{7}\) అయితే \(a : b : c\) విలువెంత?
\(a : b = 3 : 5\), \(b : c = 4 : 7\)
\(a : b : c = (3 \times 4) : (5 \times 4) : (5 \times 7)\)
= 12 : 20 : 35
23. \(a : b = 5 : 9\), \(b : c = 4 : 7\) అయితే \(a : b : c\) విలువెంత?
\(a : b : c = (5 \times 4) : (9 \times 4) : (9 \times 7)\)
= 20 : 36 : 63
24. భూమిపై 90 కిలోల బరువు గల ఒక స్త్రీ బరువు చంద్రుడిపై 15 కిలోలైతే, భూమిపై 60 కిలోల బరువు గల స్త్రీ బరువు చంద్రుడిపై ఎంత ఉండును?
భూమిపై 90 kg = చంద్రుడిపై 15 kg
భూమిపై 60 kg = చంద్రుడిపై తక్కువ
\(= \frac{60}{90} \times 15\)
= 10 kg
25. రెండు సంఖ్యల నిష్పత్తి 1 : 2. వాటికి 7 కలుపగా నిష్పత్తి 3 : 5 గా మారినచో వాటిలో గరిష్ట సంఖ్య ఏది?
రెండు సంఖ్యలు \(1x, 2x\) అనుకొనుము.
\(\frac{1x + 7}{2x + 7} = \frac{3}{5}\)
\(5(1x + 7) = 3(2x + 7)\)
\(5x + 35 = 6x + 21 \Rightarrow 6x - 5x = 35 - 21 \Rightarrow x = 14\)

గరిష్ట సంఖ్య = 28
26. \(2x + 3y : 3x + 5y = 18 : 29\) అయితే \(x : y\) విలువెంత?
\(\frac{2x + 3y}{3x + 5y} = \frac{18}{29}\)
\(29(2x + 3y) = 18(3x + 5y)\)
\(58x + 87y = 54x + 90y\)
\(58x - 54x = 90y - 87y \Rightarrow 4x = 3y \Rightarrow \frac{x}{y} = \frac{3}{4}\) (పేపర్‌లో సరిచేసిన ప్రకారం: \(x = 3y \Rightarrow x : y = 3 : 1\))
x : y = 3 : 1

28. రెండు సంఖ్యల నిష్పత్తి 2 : 3. అందులో ప్రతీ సంఖ్యకు 5 కలుపగా నిష్పత్తి 5 : 7 గా మారినచో ఆ సంఖ్యలేవి?
