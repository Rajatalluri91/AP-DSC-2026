1.3 వికాస నియమాలు (వికాస సూత్రాలు)

1. వికాస అవిచ్ఛిన్న నియమము లేదా నిరంతర నియమం :

👉 ఫలదీకరణం జరిగినప్పటి నుండి శిశువు జన్మించి, పెద్దవాడై, మరణించే వరకు వికాసము ఎలాంటి విచ్ఛిన్నము లేకుండా ఒక ప్రవాహంలా నిరంతరము కొనసాగుతూ ఉంటుంది అని వివరించేదే వికాస నిరంతర నియమం.

📝 Application :
నాగేశ్వరరావు మాస్టారులో పుట్టినప్పటి నుండి ఇప్పటి వరకు ఆయా వికాసాలు ఎలాంటి అంతరాయము లేకుండా ఆగిపోకుండా నిరంతరము అభివృద్ధి చెందుతూ ఉన్నాయి. దీనిని వివరించే వికాస నియమము — వికాస నిరంతర నియమము.

2. వికాస దిశా నియమము లేదా వికాస రెండు నిర్దిష్ట పోకడల నియమం :

👉 వికాసము రెండు నిర్దిష్ట దిశలలో జరుగుతుంది అని ఈ నియమం వివరిస్తుంది. అవి :

  • 1) శిరోపాదాభిముఖ నియమం
  • 2) సమీప దూరస్థ నియమము

1. శిరోపాదాభిముఖ నియమం :

వికాసము తల నుండి ప్రారంభమై అనుదైర్ఘ్యంగా పాదాల వైపుకు కొనసాగుతుంది అని వివరించేదే శిరోపాదాభిముఖ నియమం. (వికాసము నిలువుగా కొనసాగుతుంది).

📝 Application :
చలన వికాసంలో భాగంగా శిశువు ముందు తల నిలిపిన తరువాత మొండెంను కూర్చోబెట్టగలుగుతాడు. చివరగా కాళ్ళపై నిలబడగలుగుతాడు అన్నది ఏ దిశా నియమమును వివరిస్తుంది — శిరోపాదాభిముఖ నియమం.
📌 Note :
ఈ నియమాన్ని అనుసరించే గర్భస్థ శిశువులో కూడా మొదట తల ఏర్పడి, తరువాతనే మొండెం, కాళ్ళు ఏర్పడతాయి. అలాగే శిశువు జన్మించేటప్పుడు కూడా మొదట తల బయటకు వచ్చి మొండెం, కాళ్ళు బయటకు వస్తాయి.

2. సమీప దూరస్థ వికాస నియమం :

వికాసము దేహ మధ్యస్థ భాగాన ప్రారంభమై, వెలుపలకు దూరంగా ఉన్న భాగాల వైపుకు (చేతుల వైపుకు) విస్తరిస్తుంది అని వివరించే నియమమే సమీప దూరస్థ నియమము. (వికాసము అడ్డంగా కొనసాగుతుంది).

📝 Application :
ఒక వస్తువును అందుకునేటప్పుడు మొదట దేహ మధ్య భాగం నుండి భుజంను కదిలించి, తరువాత చేతిని చాచి, మణికట్టుని వంచి, చివరగా వేళ్ళతో వస్తువుని అందుకుంటారు. దీనిని వివరించే వికాస దిశా నియమం — సమీప దూరస్థ నియమము.
(వికాసము అడ్డంగా కొనసాగుతుంది. ప్రతి కృత్యమును చేతులతోనే చేస్తాము, అందుకే చేతులు దేహమునకు వెలుపలంగా ఉంటాయి).
📌 Note :
ఈ నియమం ప్రకారం శిశువుకు మొదట పెద్ద కండరాలపై అదుపు వచ్చి, తర్వాత చిన్న కండరాలపై అదుపు వస్తుంది.

3. వికాస క్రమానుగత నియమం / వికాసం ఒక ఖచ్చిత నమూనాను అనుసరించే నియమం :

👉 వ్యక్తిలో జరిగే ఏ వికాసం అయినా ఒక క్రమ పద్ధతిలో, సార్వత్రికమైన నమూనాని అనుసరిస్తుంది అని వివరించే నియమమే — వికాస క్రమానుగత నియమం.

📌 Note :
ఇక్కడ సార్వత్రికమైన క్రమము ఉంటుంది కానీ ఒక దాని ఆధారంగా మరొకటి ఉండదు. ఈ క్రమము ప్రతి శిశువులో ఒకేలా ఉంటుంది. ఒకే దశలో ఉంటుంది.
📝 Application :
• జ్ఞానేంద్రియ వికాసంలో భాగంగా ప్రతి శిశువులో మొదట స్పర్శ వికాసం, తదుపరి రుచి వికాసం, తదుపరి వాసన వికాసం, తదుపరి వినికిడి వికాసం, చివరగా దృష్టి వికాసము జరుగుతాయి. దీనిని వివరించే వికాస నియమము — వికాస క్రమానుగత నియమం.

• ఒక ఉపాధ్యాయుడు విద్యార్థికి మొదట వృత్తంను గీయటం నేర్పి తర్వాత చతురస్రమును గీయటం నేర్పుతున్నట్లయితే ఇక్కడ ఉపాధ్యాయుడు ఏ వికాస నియమమును అనుసరిస్తున్నట్లుగా భావించవచ్చు — వికాస క్రమానుగత నియమం.

4. వికాసం అంచనా నియమం లేదా వికాస ప్రాగుక్తీకరణ నియమం :

👉 ఒక దశలోని ప్రస్తుత వికాస వేగం ఆధారంగా ఒక శిశువు రాబోయే దశలో ఆ వికాసంలో ఎంత అభివృద్ధి చెందుతాడో అంచనా వేయవచ్చు అని వివరించే నియమమే — వికాస ప్రాగుక్తీకరణ నియమం.

📝 Application :
• పూర్వ బాల్యదశలో ఎత్తుని బట్టి, కౌమారదశ పూర్తయ్యే నాటికి పిల్లవాడు ఎంత ఎత్తుకు ఎదగలుగుతాడో ఊహించి చెప్పవచ్చు. దీనిని వివరించే వికాస నియమం — వికాస ప్రాగుక్తీకరణ నియమం.

• 5వ తరగతి విద్యార్థి ప్రస్తుతం గీస్తున్న బొమ్మలను బట్టి అతడు భవిష్యత్తులో మంచి చిత్రకారుడిగా రాణించే అవకాశం ఉంది అని ఉపాధ్యాయుడు ఆ పిల్లవాని తల్లిదండ్రులతో చెప్పినాడు. ఈ వాక్యము ఏ వికాస నియమాన్ని వివరిస్తుంది — వికాస ప్రాగుక్తీకరణ నియమం.

5. వికాస వైయక్తిక భేదాల నియమం :

👉 వికాసము ఒక క్రమ పద్ధతిలో జరిగినప్పటికీ అది అందరిలో ఒకే వేగంగా, ఒకే గుణాత్మకంగా జరగదు అని వివరించే వికాస నియమమే — వికాస వైయక్తిక భేదాల నియమం.

📝 Application :
• ఒకే రోజు పుట్టిన రాధ, శ్రుతులలో చలన వికాసంలో రాధ సంవత్సరం నిండే నాటికి పరిగెత్తుతుంటే శ్రుతి ఆనాటికి లేచి నిలబడడమే చేయలేకపోతుంది. దీనిని వివరించే వికాస నియమం — వికాస వైయక్తిక భేదాల నియమం.

• కవల సోదరులైన రాము, సుబ్బులలో భాషా వికాసంలో భాగంగా 1½ సం॥రం వయస్సులో రాము, చిన్న చిన్న వాక్యాలు మాట్లాడుతుంటే, సుబ్బు ఇప్పటికీ ఇంగితాలు మాత్రమే మాట్లాడగలగటంను వివరించే వికాస నియమం — వికాస వైయక్తిక భేదాల నియమం.

6. వికాసము సాధారణం నుండి నిర్దిష్టం వైపుకు జరుగుతుంది అనే నియమం :

👉 ఏ వికాసానికి సంబంధించి అయినా శిశువు మొదట సాధారణ ప్రతిస్పందనలను కనపరచి, తరువాత నిర్దిష్టమైన లేదా ప్రత్యేకమైన ప్రతిస్పందనలను కనబరుస్తారని వివరించే నియమమే — వికాసం సాధారణం నుండి నిర్దిష్టం వైపుకు జరుగుతుంది.

📝 Application :
• ఉద్వేగ వికాసంలో భాగంగా, శిశువు మొదట అన్ని బాధాకరమైన సంఘటనలకు సాధారణ ఉద్రిక్తత అయిన విచారాన్ని మాత్రమే కనబరుస్తాడు. అది క్రమంగా అసూయ, కోపం, భయం అనే నిర్దిష్టమైన ప్రతిస్పందనలుగా విడిపోవటం అనేది జరుగుతుంది. దీనిని వివరించే వికాస నియమం — వికాసం సాధారణం నుండి నిర్దిష్టం వైపుకు జరుగుతుంది.

• మొదట్లో సాధారణంగా రెండు చేతులతో బొమ్మను పట్టుకునే శిశువు క్రమేపీ తన చేతి వేళ్ళతో బొమ్మని పట్టుకోగలుగుతుంది. దీనిని వివరించే వికాస నియమం — వికాసం సాధారణం నుండి నిర్దిష్టానికి జరుగుతుంది.
📌 Note :
అందుకే క్రింది తరగతులలో సామాన్య మౌలిక భావనలను పరిచయం చేసి పై తరగతులలో నిర్దిష్ట అంశములను విస్తృతంగా వివరిస్తారు.
ఉదా : జ్ఞానేంద్రియములపై సాధారణ అవగాహనను క్రింది తరగతులలో కల్పించి పై తరగతులలో ప్రతి జ్ఞానేంద్రియమును నిర్దిష్టంగా వివరిస్తారు.

7. వికాస సంచిత నియమం :

👉 ఏదైనా ఒక వికాస కృత్యం దాని ముందు విజయవంతంగా నెరవేర్చబడిన వికాస కృత్యం ఆధారంగా జరిగినట్లయితే దానిని వికాస సంచిత నియమం అంటారు.

📌 Note :
ఈ నియమంలో ఒక వికాస కృత్యం ఆధారంగా మరొకటి జరుగుతూ ఉంటుంది.
📝 Application :
• ఒక విద్యార్థి రేఖాఖండంను గీయటం నేర్చుకొని దాని ఆధారంగా చతురస్రమును గీయటం, చతురస్రం ఆధారంగా సమఘనాన్ని గీయటం నేర్చుకున్నట్లయితే దీనిని వివరించే వికాసం నియమం — వికాస సంచిత నియమం.

• ఒక ఉపాధ్యాయుడు కూడికల ఆధారంగా గుణకారాలు, తీసివేతల ఆధారంగా భాగహారాలను విద్యార్థులకు నేర్పుతున్నట్లయితే ఆ ఉపాధ్యాయుడు అనుసరించిన వికాస నియమం — వికాస సంచిత నియమం.

8. వికాసము అన్ని దశలలో ఒకే రకంగా జరగదు అనే నియమం :

👉 వికాసము జీవిత పర్యంతం జరిగినప్పటికీ, అన్ని దశలలో ఒకే రకంగా జరగదు. కొన్ని దశలలో ఎక్కువ వేగంతో, మరికొన్ని దశలలో తక్కువ వేగంతో జరుగుతుంది అని వివరించే నియమమే — వికాసం అన్ని దశలలో ఒకే రకంగా జరగదు అనే నియమం.

📝 Application :
శైశవ దశలో మిగిలిన అన్ని దశల కంటే పెరుగుదల అత్యంత వేగంగా జరుగుతుంది. అలాగే ఉత్తర బాల్యదశలో పెరుగుదల మిగిలిన అన్ని దశల కంటే నెమ్మదిగా జరుగుతుంది. దీనిని వివరించే వికాస నియమము — వికాసము అన్ని దశలలో ఒక రకంగా జరగదు.

9. వికాస సమైక్య నియమం / వికాస సమగ్ర నియమం / వికాసం ఏకీకృత మొత్తంగా జరిగే నియమం / వికాస పరస్పర సంబంధ నియమం :

👉 వ్యక్తిలోని విభిన్న వికాసాలన్నీ విడివిడిగా కాక, అన్నీ కలిసి సమైక్యంగా పనిచేస్తేనే వ్యక్తి యొక్క సంపూర్ణ వికాసం జరుగుతుంది అని వివరించేదే — వికాస పరస్పర సంబంధ నియమం.

📝 Application :
మానసిక వికాస లోపంలో ఉన్న విద్యార్థి, మిగిలిన అన్ని వికాసాలతో వెనుకబడిపోయి ఉంటాడు. అతడిలో సంపూర్ణ వికాసం జరగదు. దీనికి కారణాన్ని వివరించే వికాస నియమం — వికాస పరస్పర సంబంధ నియమం.
